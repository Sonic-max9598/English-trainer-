# English Intensive — правила работы

## Навыки (обязательно)
В `.claude/skills/` установлены навыки из github.com/anthropics/skills. Используй их во всей работе над проектом:
- **frontend-design** — перед любым изменением интерфейса или вида: план (цвета, шрифты, раскладка, принципы), сверка с задачей, затем код и самокритика по скриншотам.
- **theme-factory** — при смене или создании цветовой темы / шрифтов: показать варианты (`theme-showcase.pdf`), дождаться выбора, применить.
- **webapp-testing** — проверка каждого изменения скриптами Python Playwright (`file://` для `index.html`): консоль без ошибок, ширина 375px без горизонтальной прокрутки, светлая и тёмная тема, скриншоты.

## Проект
- Приложение — один файл `index.html`, собирается из `src/` и `data/` командой `node build.js`. Не правь `index.html` вручную.
- Тестовая сборка с отладочным доступом: `TEST=1 node build.js` → `test-build.html` (в .gitignore).

## Нельзя ломать
- Ключи localStorage `tenses3`, `tenses3prog`, `tenses3words`, `tenses3own` — прежний формат; новые данные только в `tenses3x`.
- Проверку ответов (варианты, сокращения), интервальный повтор, озвучку, голосовой ввод.
- Клавиатура не закрывается после «Проверить».
