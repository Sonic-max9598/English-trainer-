# English Intensive — правила работы

## Навыки (обязательно)
В `.claude/skills/` установлены навыки из github.com/anthropics/skills. Используй их во всей работе над проектом:
- **frontend-design** — перед любым изменением интерфейса или вида: план (цвета, шрифты, раскладка, принципы), сверка с задачей, затем код и самокритика по скриншотам.
- **theme-factory** — при смене или создании цветовой темы / шрифтов: показать варианты (`theme-showcase.pdf`), дождаться выбора, применить.
- **webapp-testing** — проверка каждого изменения скриптами Python Playwright (`file://` для `index.html`): консоль без ошибок, ширина 375px без горизонтальной прокрутки, светлая и тёмная тема, скриншоты.

## Проект
- Приложение — `index.html` + `sw.js` (офлайн-кэш), `manifest.json`, `icons/`, `fonts/`. `index.html` и `sw.js` собираются из `src/` и `data/` командой `node build.js` (версия кэша считается по содержимому). Не правь их вручную.
- Иконки: `node tools/make-icons.js && python3 tools/make-icons.py`.
- Сервер админки — `server/` (Render, `render.yaml`): журнал класса и сообщение ученикам; в приложении — `src/cloud.js` (настройка «Учитель онлайн», данные в `tenses3x.cloud`). Адрес сервера задаётся при сборке: `API_URL=... node build.js`. Тесты сервера: `cd server && npm test`.
- Тестовая сборка с отладочным доступом: `TEST=1 node build.js` → `test-build.html` (в .gitignore).

## Нельзя ломать
- Ключи localStorage `tenses3`, `tenses3prog`, `tenses3words`, `tenses3own` — прежний формат; новые данные только в `tenses3x`.
- Проверку ответов (варианты, сокращения), интервальный повтор, голосовой ввод, озвучку (src/speech.js: чтение ответа после проверки, кнопки-динамики, режим «Выбери на слух», формы неправильных глаголов; настройки «Читать ответ вслух» и «Медленно»).
- Работу без интернета: каждый новый файл, нужный приложению, должен попадать в список кэша в `build.js`.
- Клавиатура не закрывается после «Проверить».
