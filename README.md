# English Intensive — тренажёр английского

Приложение для iPhone и компьютера: 12 времён, смешанные времена, артикли, 3000 слов A1–C1 и справочник по всей грамматике. Работает без интернета (PWA): открой один раз, затем «Поделиться → На экран „Домой“».

Онлайн через GitHub Pages: https://sonic-max9598.github.io/English-trainer-/ (Settings → Pages → Deploy from a branch → main, / (root)).

## Что внутри
- **Сегодня** — учитель (Мистер Сэм или Мисс Лола), серия дней, опыт и уровни, программа дня, задания, тропа 12 времён через луг, лес, холмы и озеро к снежным горам, награды.
- **Учить** — времена (перевод, «собери», «выбери время», смешанные времена, таймер), артикли, слова (план дня, свободная практика, словарь). Уроки по 10 заданий.
- **Теория** — книга из 31 главы: 12 времён и согласование, вопросы, порядок слов, there is, артикли, существительные, местоимения, прилагательные, наречия, предлоги, модальные глаголы, пассив, герундий и инфинитив, фразовые глаголы, used to, условные 0–3, косвенная речь, wish. В каждой главе — объяснение, примеры с переводом на русский и узбекский, частые ошибки и мини-тест на 5 вопросов. Поиск, закладка места, отметка «прочитано», размер текста.

## Исходники
- `src/` — разметка, стили (`style.css`), код (`app.js` и модули: `teacher.js`, `tense.js`, `words.js`, `game.js`, `book.js`, `pwa.js`), теория (`theory-tenses.js`, `theory-book.js`), шаблон service worker (`sw.js`).
- `data/tenses-*.txt` — предложения для времён: `время|форма|ru|uz|en|варианты через ;|подсказка`.
- `data/mixed.txt` — смешанные времена: `тип|ru|uz|en|варианты через ;|слова|почему эти времена`. Ответ с переставленными частями («Y when X» вместо «When X, Y») принимается автоматически.
- `data/words-*.txt` — словарь: `@Уровень|CEFR`, `#Тема`, `word|перевод ru|перевод uz|пример`.
- `fonts/` — Nunito и Literata (OFL), `icons/` — иконки приложения, `tools/` — генератор иконок.

Сборка: `node build.js` → `index.html` и `sw.js`. Тестовая сборка: `TEST=1 node build.js` → `test-build.html`.

Прогресс хранится в localStorage (`tenses3`, `tenses3prog`, `tenses3words`, `tenses3own` — формат прежний; всё новое — опыт, серия, учитель, закладки теории, смешанные времена — в `tenses3x`). На iPhone приложение с экрана «Домой» хранит данные отдельно от Safari — для переноса есть код прогресса в Настройках.
