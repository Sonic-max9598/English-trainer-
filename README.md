# English Intensive — тренажёр английского

Готовое приложение — один файл `Тренажёр времён.html` (открывается в браузере, работает офлайн).

Исходники для правок:
- `src/` — разметка, стили (`style.css`) и код (`app.js`);
- `data/tenses-*.txt` — предложения для времён: `время|форма|ru|uz|en|варианты через ;|подсказка`;
- `data/words-*.txt` — словарь: `@Уровень|CEFR`, `#Тема`, `word|перевод ru|перевод uz|пример` (примеры к базовым словам — в `data/examples-base.txt`).

Сборка в один HTML: `node build.js`.

Экраны: «Сегодня» (серия дней, опыт и уровни, программа дня 10+15 минут, задания дня, карта 12 времён, достижения), «Учить» (времена, артикли, слова — уроки по 10 заданий), теория, прогресс, настройки.

Прогресс хранится в localStorage (`tenses3`, `tenses3prog`, `tenses3words`, `tenses3own` — формат прежний; новое — опыт, серия, расписание повторов — в отдельном ключе `tenses3x`).
